# Kolejka aktywna

1. Synchronizacja 1LM tworzy/importuje kolejkę jako szkic.
2. Administrator otwiera kolejkę w module Kolejki.
3. Administrator podaje dokładną datę i godzinę zamknięcia typowania.
4. Otwarcie nowej kolejki zamyka inną otwartą kolejkę tego samego sezonu.
5. Po osiągnięciu terminu `closes_at` kolejka jest automatycznie zamykana do nowych kuponów.
6. Rozpoczęte i historyczne kolejki pozostają widoczne jako wyniki/historia, ale nie przyjmują zmian.
