# Frontend 0.2.0

Każdy mecz ma dwa kafelki zespołów. Kliknięcie zespołu oznacza go jako wybranego zwycięzcę (zielony), a rywala jako odrzuconego (czerwony). Pełna nazwa zespołu jest zawijana bez ucinania. Mecz Decki Pelplin jest wyróżniany obramowaniem całego modułu.

Przycisk zapisu jest dostępny dopiero po wskazaniu zwycięzców wszystkich meczów. Przed wysłaniem wyświetlany jest modal z ostrzeżeniem, że kuponu nie będzie można później zmienić.
