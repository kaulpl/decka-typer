# 0.2.0

Decka Typer przechodzi na prosty model wyboru zwycięzcy. Kupon obejmuje całą kolejkę i po zatwierdzeniu jest nieodwracalnie blokowany. Administrator kontroluje otwieranie kolejki oraz termin zamknięcia typowania. Wersja usuwa Apple ID, poprawia czas z terminarza 1LM i uruchamia `/typer` jako samodzielny, pełnoekranowy widok.
